# fluffy-giggle

Прототип: слабая LLM обрабатывает обращения с персональными данными, сильная только советует.
Все модели — внешние endpoint'ы, граница приватности логическая и живёт в коде.

- `core/` — Go 1.27, один сервис на uber-fx, SQLite, вшитый фронт. См. [core/AGENTS.md](core/AGENTS.md).
- `web/` — React 19 + Vite. См. [web/AGENTS.md](web/AGENTS.md).
- `docs/` — [карта системы](docs/architecture/overview.md), [ADR](docs/adr/), [спеки](docs/specs/).

## Команды

| Команда | Что делает |
|---|---|
| `make env` | `core/.env` из `.env.example` |
| `make run` / `make web` | бэкенд на `:8000` / фронт на `:5173` |
| `make build` | один бинарь со вшитым фронтом в `core/bin/` |
| `make generate` | sqlc + mockgen; результат коммитится |
| `make fmt` / `make lint` / `make test` | форматирование / линтеры / тесты |

## Порядок работы

1. Любая задача начинается с уточняющих вопросов; развилка — вопрос, а не догадка.
2. Задача крупнее дня или меняющая контракт — спека в `docs/specs/NNNN-slug/`. Решение, которое дороже отменить, чем принять, — ADR.
3. Код + тесты. `make fmt && make lint && make test` до коммита.
4. Коммит и пуш — только после подтверждения человеком.

## Контракт

- Источник истины — `core/api/openapi.yml`, меняется вместе с кодом.
- Ручки под `/v1`, кроме `/health`. JSON — `snake_case`, фронт маппит в `camelCase` в `web/src/lib/`.
- Аутентификация — HTTP Basic с логином и паролем из env через форму в SPA; `401` без `WWW-Authenticate`.
- Фронт ходит в API со своего origin: в проде вшит в бинарь, в dev Vite проксирует `/v1`.

## Конфигурация

Только env: поле в `core/internal/config` с тегом `env:` и строка в `core/.env.example`. Секреты — в `.env` и в CI.

## Язык

Код, комментарии, коммиты, логи — английский. Интерфейс, OpenAPI, `docs/` — русский.
Conventional Commits: `feat(core): ...`, `fix(web): ...`, `docs: ...`.

## Границы

**Всегда** — тест на новое поведение; `make generate` после правки `.sql` или портов.
**Спроси** — новая зависимость, миграция, правка контракта, CI, Dockerfile, Makefile.
**Никогда** — секреты в репозиторий; правка `**/sqlc/`, `**/mock/`, `web/src/components/ui/`; коммит без подтверждения.
