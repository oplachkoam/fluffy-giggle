# 0004 — HTTP Basic из env через собственную форму

| | |
|---|---|
| **Статус** | Принято |
| **Дата** | 2026-11-03 |

## Контекст

Один оператор, логин и пароль заданы в env. Сессий и ролей не нужно, но браузерный диалог Basic не нужен тоже.

## Варианты

- **A.** Cookie-сессия с непрозрачным токеном.
- **B.** HTTP Basic: SPA хранит логин и пароль и шлёт `Authorization: Basic`; сервер отвечает `401` без `WWW-Authenticate`.
- **C.** Ключ API в заголовке.

## Решение

B. Сравнение хешей в constant time; `/health` и SPA открыты; SSE идёт через `fetch` с тем же заголовком, потому что `EventSource` заголовков не ставит.

## Почему

A добавляет состояние на сервере ради одного пользователя; C требует выдавать ключ отдельно от пары из env. B — ноль состояния и одна форма.

## Последствия

- Плюс: нечего хранить и отзывать, смена пароля — рестарт.
- Минус: пара в localStorage доступна скрипту на странице. Принято: SPA без сторонних скриптов, один оператор.
