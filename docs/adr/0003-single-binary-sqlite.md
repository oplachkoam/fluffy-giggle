# 0003 — Один бинарь: SQLite без CGO, миграции на старте, SPA внутри

| | |
|---|---|
| **Статус** | Принято |
| **Дата** | 2026-11-03 |

## Контекст

Деплоится только бинарь; инфраструктуры вокруг нет. Нужны история запусков, шаги с payload и картинки.

## Варианты

- **A.** Postgres рядом, миграции отдельным инструментом.
- **B.** SQLite в одном файле, драйвер без CGO, миграции встроены и применяются при запуске, фронт вшит через `go:embed`.
- **C.** Только память, без истории.

## Решение

B. `modernc.org/sqlite`, WAL, `busy_timeout`; `migrations/*.sql` накатываются из бинаря в `schema_migrations`; изображения — блобом с лимитом 10 МБ; `npm run build` пишет в `ui/dist`, Go вшивает.

## Почему

A требует второй процесс и отдельный шаг деплоя. C теряет трассу после рестарта, а трасса и есть продукт. B — `CGO_ENABLED=0`, кросс-компиляция и образ из одного файла.

## Последствия

- Плюс: один артефакт, один том `/data`.
- Минус: один писатель; параллельные воркеры ждут на `busy_timeout`. Для прототипа достаточно.
